# Atmos Implementation Plan

> Execution: native in this session, with a fresh whole-project review at the end. User authorizes all phases without approval pauses.

**Goal:** Build the real-data weather platform in the pasted specification.
**Architecture:** Next.js App Router, provider-owned requests, validated server proxy, persistent client state, lazy specialist views.
**Tech stack:** Current stable Next.js, React, TypeScript, Tailwind, Radix UI, TanStack Query, Zustand, MapLibre, Recharts, Zod, Vitest, Playwright.
**Spec:** ../specs/2026-10-06-atmos-design.md

## Global constraints

No fake weather; no raw provider calls in components; location timezone; null means unavailable; observational radar distinct from model samples; optional providers fail independently; English UI with Dutch navigation architecture; local workspace delivery.

## Review focus

Malformed provider arrays must be rejected. Null variables must show unavailable. DST must not change chart ordering. Rapid location switches must abort prior requests. Inland marine and unavailable radar must leave the application usable.
